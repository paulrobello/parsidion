core.vault_schema

Typed schema for the Parsidion vault config (ENH-014).

Single source of truth for the config schema: section names, key names, and the allowed Python types for each key. Each top-level config section is a dataclass whose field annotations reproduce the allowed-type tuples the hand-maintained _CONFIG_SCHEMA literal in vault_config previously encoded by hand. schema_dict() derives that structure from the annotations so validation can consume one source of truth.

ENH-017: every field also carries metadata={"doc": ..., "read_by": ...} — a one-line description and the modules that read the key — and the section docstrings carry the prose that used to live only in templates/config.yaml. scripts/gen_config_docs.py generates the CLAUDE.md config table, the docs/ARCHITECTURE.md reference block, and the template from this module, and CI fails when the committed copies drift. Optional metadata keys: example (a template-recommended value that differs from the code default), reserved (True when no code reads the key yet — the schema-vs-code coverage test allows exactly these), section_read (True when the whole section is consumed as one mapping, keys forwarded verbatim — e.g. anthropic_env).

Stdlib-only (dataclasses + typing). Values pass through unchanged -- no coercion, no canonical defaults invented. A field value of None means "absent from the file", mirroring the dict load_config() returns. Validation (unknown keys, type mismatches) stays warn-only and lives in vault_config.validate_config(); this module never raises on shape.

The dataclasses deliberately default every field to None even when the field's allowed-type tuple does not include NoneType (e.g. backend: str defaulting to None). The annotation says what config.yaml values are valid; the default says what an unset field holds. validate_config already treats an explicit None value as "skip the type check", so the two notions are consistent.

1086@dataclass
1087class VaultAppConfig:
1088    """Typed view of the parsed vault config.
1089
1090    Every section is always present: an absent (or non-mapping) section in
1091    the file yields an empty instance of its dataclass (all fields ``None``),
1092    so consumers can chain ``cfg.session_start_hook.ai_model`` without
1093    None-guarding the section itself. Whether a section was *explicitly* set
1094    in the file is not distinguishable from this view (check the dict from
1095    :func:`load_config` if you need that); individual field values are
1096    ``None`` for keys absent from the file. Construct via :meth:`from_dict`
1097    or :func:`vault_config.load_typed_config`; the dataclasses carry no
1098    validation -- that remains :func:`vault_config.validate_config`'s job.
1099    """
1100
1101    # ``default_factory=lambda: X()`` (rather than ``= X``) sidesteps a pyright
1102    # overload-resolution hiccup that arises under ``from __future__ import
1103    # annotations`` when the factory is a dataclass whose own fields use the
1104    # ``attr: str = None`` pattern the module-level reportAssignmentType
1105    # suppression covers.
1106    ai: AIConfig = field(default_factory=lambda: AIConfig())
1107    ai_models: AIModelsConfig = field(default_factory=lambda: AIModelsConfig())
1108    claude_cli: ClaudeCliConfig = field(default_factory=lambda: ClaudeCliConfig())

1115        default_factory=lambda: SessionStopHookConfig()
1116    )
1117    subagent_stop_hook: SubagentStopHookConfig = field(
1118        default_factory=lambda: SubagentStopHookConfig()
1119    )
1120    user_prompt_submit_hook: UserPromptSubmitHookConfig = field(
1121        default_factory=lambda: UserPromptSubmitHookConfig()
1122    )
1123    pre_compact_hook: PreCompactHookConfig = field(
1124        default_factory=lambda: PreCompactHookConfig()
1125    )
1126    summarizer: SummarizerConfig = field(default_factory=lambda: SummarizerConfig())
1127    embeddings: EmbeddingsConfig = field(default_factory=lambda: EmbeddingsConfig())
1128    parsight: ParsightConfig = field(default_factory=lambda: ParsightConfig())
1129    search: SearchConfig = field(default_factory=lambda: SearchConfig())
1130    anthropic_env: AnthropicEnvConfig = field(
1131        default_factory=lambda: AnthropicEnvConfig()
1132    )
1133    git: GitConfig = field(default_factory=lambda: GitConfig())
1134    defaults: DefaultsConfig = field(default_factory=lambda: DefaultsConfig())
1135    event_log: EventLogConfig = field(default_factory=lambda: EventLogConfig())
1136    adaptive_context: AdaptiveContextConfig = field(
1137        default_factory=lambda: AdaptiveContextConfig()
1138    )
1139    vault: VaultSectionConfig = field(default_factory=lambda: VaultSectionConfig())
1140    transcripts: TranscriptsConfig = field(default_factory=lambda: TranscriptsConfig())
1141    adapters: AdaptersConfig = field(default_factory=lambda: AdaptersConfig())
1142
1143    @classmethod
1144    def from_dict(cls, parsed: dict[str, Any]) -> VaultAppConfig:
1145        """Map a parsed config dict onto the section dataclasses.
1146
1147        Values pass through unchanged -- no coercion. Absent keys default to
1148        ``None`` on the section dataclass. Unknown sections/keys and non-mapping
1149        section values are skipped silently; :func:`vault_config.validate_config`
1150        is responsible for warning about them.
1151
1152        Args:
1153            parsed: The dict returned by :func:`vault_config.load_config`.
1154
1155        Returns:
1156            A populated :class:`VaultAppConfig`. Returns an instance whose
1157            sections are all empty (every field ``None``) when *parsed* is not
1158            a dict.
1159        """
1160        if not isinstance(parsed, dict):
1161            return cls()
1162
1163        hints = get_type_hints(cls)
1164        kwargs: dict[str, Any] = {}
1165        for f in fields(cls):
1166            section_cls = _unwrap_optional(hints[f.name])
1167            # ``is_dataclass`` alone narrows ``Any`` to the instance protocol
1168            # (not callable); gating on ``isinstance(..., type)`` first lets
1169            # pyright see a class we can instantiate.
1170            if not (isinstance(section_cls, type) and is_dataclass(section_cls)):
1171                continue
1172            raw_section = parsed.get(f.name)
1173            if not isinstance(raw_section, dict):
1174                continue
1175            sub_kwargs: dict[str, Any] = {}
1176            for sub_f in fields(section_cls):
1177                if sub_f.name in raw_section:
1178                    sub_kwargs[sub_f.name] = raw_section[sub_f.name]
1179            kwargs[f.name] = section_cls(**sub_kwargs)
1180        return cls(**kwargs)

1188def schema_dict() -> dict[str, dict[str, tuple[type, ...]]]:
1189    """Derive the ``section -> key -> allowed-types`` schema from annotations.
1190
1191    The structure mirrors the hand-maintained ``_CONFIG_SCHEMA`` literal:
1192    each section dataclass field's annotation becomes an allowed-types tuple.
1193    A bare type (e.g. ``str``) yields ``(str,)``; a union (e.g. ``int | float``)
1194    yields ``(int, float)`` preserving annotation order; ``None`` in a union
1195    maps to ``type(None)`` (``NoneType``), matching the convention
1196    ``validate_config`` already uses to filter None out of warning messages.
1197    """
1198    result: dict[str, dict[str, tuple[type, ...]]] = {}
1199    top_hints = get_type_hints(VaultAppConfig)
1200    for f in fields(VaultAppConfig):
1201        section_cls = _unwrap_optional(top_hints[f.name])
1202        if not (isinstance(section_cls, type) and is_dataclass(section_cls)):
1203            continue
1204        section_hints = get_type_hints(section_cls)
1205        section_schema: dict[str, tuple[type, ...]] = {}
1206        for sub_f in fields(section_cls):
1207            section_schema[sub_f.name] = _annotation_to_allowed_types(
1208                section_hints[sub_f.name]
1209            )
1210        result[f.name] = section_schema
1211    return result

1214def _unwrap_optional(tp: Any) -> Any:
1215    """Return the single non-``None`` arg of an Optional union, else *tp*.
1216
1217    ``ai: AIConfig | None`` resolves to a union whose ``__args__`` are
1218    ``(AIConfig, NoneType)``; this returns ``AIConfig`` so callers can inspect
1219    the section dataclass directly. Unions with multiple non-None args (none
1220    here today, but defensively) and non-union types are returned unchanged.
1221    """
1222    args = getattr(tp, "__args__", None)
1223    if args is None:
1224        return tp
1225    non_none = [a for a in args if a is not type(None)]
1226    if len(non_none) == 1:
1227        return non_none[0]
1228    return tp

1231def _annotation_to_allowed_types(ann: Any) -> tuple[type, ...]:
1232    """Turn a resolved annotation into the allowed-types tuple.
1233
1234    A bare type has no ``__args__`` and yields a one-tuple. A union yields
1235    its ``__args__`` as a tuple, preserving source order (e.g.
1236    ``float | int`` -> ``(float, int)``). ``None`` in a PEP 604 union arrives
1237    as ``NoneType`` in ``__args__``, which IS ``type(None)`` -- the form
1238    ``_CONFIG_SCHEMA`` used and ``validate_config``'s message filter expects.
1239    """
1240    args = getattr(ann, "__args__", None)
1241    if args is None:
1242        return (ann,)
1243    return tuple(args)
