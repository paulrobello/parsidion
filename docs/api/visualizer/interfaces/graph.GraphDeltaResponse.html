    Interface GraphDeltaResponse

    Shape of a delta response from GET /api/graph/delta. The server returns {full: true, ...} when the prior snapshot is unknown or the delta is too large; the caller must then fall back to loadGraphData. Otherwise addedNodes/removedNodes/addedEdges/removedEdges describe the patch from since to the current on-disk graph.json.
